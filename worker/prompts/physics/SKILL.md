# 高考物理解题规范

按“选研究对象与过程 → 建模并定正方向 → 写规律和约束 → 求解 → 用单位、边界和物理意义反查”完成题目。

1. 先从题干和图中提取研究对象、过程阶段、参考系、已知量、待求量及理想化条件。图片题逐项核对箭头、角度、极性、接线点、坐标刻度和初末状态；看不清就说明，不补画不存在的连接。
2. 对每个阶段明确适用模型：质点/刚体、匀变速、圆周运动、简谐近似、理想气体、点电荷、匀强场、理想电表等。模型前提不满足时不得直接套公式。
3. 建立坐标系和正方向，所有矢量分量、功、冲量、速度及电势差沿同一符号约定书写。求得负值时解释其方向或物理含义，不能无条件取绝对值。
4. 先画或文字描述受力、电路、光路或过程图，再列方程。受力分析只列作用在当前对象上的力，区分性质力与效果力；成对作用力不得画在同一对象上。
5. 使用牛顿定律前确认惯性系和研究对象；使用动量守恒前说明系统及外力冲量条件；使用机械能守恒前检查非保守力做功；使用能量守恒时写清能量转移对象，不能混用不同系统的能量式。
6. 多阶段运动按事件边界分别列式，并用位置、速度、时间、碰撞或几何约束连接。绳、杆、接触、纯滚动和不可伸长约束要写成速度/位移关系，不能只凭“同步”猜比例。
7. 电场和磁场题先判断电荷正负、场方向和运动方向，再用左/右手规则或叉乘确定力。洛伦兹力不做功；涉及加速电场、选择器、质谱或复合场时分区跟踪能量和轨迹连续性。
8. 电路题按真实节点识别串并联，检查开关状态、电表内阻、电源内阻和动态元件。写出端电压、路端功率或效率前明确所指部分；含电容时区分稳态与暂态。
9. 图像题先读横纵轴、单位和正方向，再解释斜率、截距、面积及拐点的物理意义。只有在对应定义成立时才能把斜率或面积认作物理量，并检查非线性区间。
10. 热学、振动、波和光学题区分状态量与过程量、波的传播与质点振动、光程与几何路程。使用气体定律时固定气体质量并统一温标；干涉、衍射和折射要核对相位、介质与临界条件。
11. 实验题按“目的—原理—器材量程—连接/调零—操作—数据处理—误差”作答。控制变量、重复测量和对照必须对应结论；估读位数、有效数字、图线拟合和异常点处理遵守仪器精度。
12. 多选题对每个选项独立验证，不能因一个结论成立推定同组结论。定性判断尽量给出单调关系、极限情形或决定性方程，而非口诀。
13. 数值计算先保留符号式，再统一 SI 单位代入；最终量必须带单位并按题意保留有效数字。对根号、三角函数和高精度值调用 calculator，工具只负责计算，不替代物理建模。
14. 解出候选后检查量纲、数量级、方向、取值范围、能量界、速度上限、接触条件及极端情形。方程的数学根若不满足时间为正、几何可达或模型前提，必须舍去并说明。
15. 输出按“模型/关键图示说明—核心方程—结果与单位”组织。简单题可压缩，但不得省略决定答案的受力、守恒条件、符号约定或关键约束。
